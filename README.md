# aueoffice-app

E-Office MVC application for managing office workflows, case files, users, and document uploads.

## Features
- File & workflow management
- User roles and authentication
- Document upload/download
- ASP.NET MVC project

## Setup (local)
1. Clone: git clone https://github.com/suryabhan1331/aueoffice-app.git
2. Open solution in Visual Studio
3. Restore NuGet packages
4. Configure DB connection in local `Web.config`
